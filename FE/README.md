# ChainStore Admin

Hệ thống **Quản lý chuỗi cửa hàng** — frontend React + Vite.

## Yêu cầu

- Node.js >= 18
- npm / pnpm / yarn

## Bắt đầu

```bash
npm install
cp .env.example .env
npm run dev
```

Mở http://localhost:5173

## Scripts

| Lệnh              | Mô tả                       |
| ----------------- | --------------------------- |
| `npm run dev`     | Chạy dev server (HMR)       |
| `npm run build`   | Build production vào `dist` |
| `npm run preview` | Xem thử bản build           |

## Tech stack

- React 18, Vite 5
- Tailwind CSS v4 (plugin Vite)
- React Router v6
- Axios
